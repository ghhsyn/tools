Sık sorulan sorular

      
Verilerim güvende mi?
Evet. JSON verileriniz hiçbir sunucuya gönderilmez; tüm işlemler tarayıcınızda yapılır. API anahtarı veya kişisel veri içeren JSON'ları güvenle biçimlendirebilirsiniz.

      
Hatalı JSON'u düzeltebilir mi?
Hatanın yerini satır ve sütun olarak gösterir. Tek tırnak ve sondaki virgül gibi yaygın hataları "Onar" butonu ile düzeltmeyi deneyebilirsiniz.
